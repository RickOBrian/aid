# Widget Promo Offer — прототип баннера

Статическая вёрстка адаптивного баннера и карусельного варианта (280px).

## Быстрый старт

```bash
python3 serve.py
```

Открыть: http://localhost:9876/banner-adaptive-demo.html  
Корень `/` редиректит на демо.

Другой порт:

```bash
python3 serve.py 8080
```

## Состав

- `banner-adaptive-demo.html` / `index.html` — страница прототипа
- `assets/` — иллюстрации баннеров
- `serve.py` — локальный сервер (нужен из‑за inline-ресурсов и шрифтов)

## Зависимости

- Python 3
- Интернет для Google Fonts (Inter, заголовки страницы). Montserrat встроен в HTML.

## Передача разработчикам

Можно открыть архив как есть или положить содержимое в любой static-хостинг.
