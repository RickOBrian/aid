Типографика SOUZ

Шкала и правила использования стилей типографики в нативных мобильных интерфейсах с учётом узких экранов, особенностей iOS/Android и тач-интеракций.

Это система типографики, не привязанная к конкретному продукту

Здесь указаны общие стандарты и примеры, которых следует придерживаться при создании стилей типографики для продукта. Допустимо менять шрифт, значения, оставаясь в пределах правил системы.

⚛

Основные принципы

Line Height кратен 4px

Никаких 120%, Auto и дробных значений. Все LH — чётные значения, кратные 4px, чтобы идеально ложиться в 4px grid.

Имена по ролям, а не по тегам

Не H1/H2, а Heading / L, Body / M, Label / S. Разработчики мапят это на теги, стили SwiftUI/Compose и т.д.

Body ≠ Label

Body — текст для чтения (2+ строки, высокий LH, paragraph-режим).
Label — текст для управления (кнопки, инпуты, чипы, табы; однострочный режим).

⚛

Мобильная шкала стилей (Montserrat, Mobile)

Базовая единица LH: 4px. Шкала балансирует читаемость и экономию вертикального пространства.

Display

Акцентные — редкие, для онбординга/paywall

Не рекомендуется использовать внутри обычных скролл-экранов с контентом и формами.

Heading

Заголовки мобильного интерфейса. Оптимизированы под 1–2 строки. Если уходит в 3+ строки — снижай уровень или сокращай текст.
