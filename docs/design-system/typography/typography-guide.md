# Типографика SOUZ — Архитектурный гайд

> Шкала и правила использования стилей типографики в нативных мобильных интерфейсах
> с учётом узких экранов, особенностей iOS/Android и тач-интеракций.

> **Это система типографики, не привязанная к конкретному продукту.**
> Здесь указаны общие стандарты и примеры, которых следует придерживаться при создании
> стилей типографики для продукта. Допустимо менять шрифт, значения, оставаясь в пределах
> правил системы.

Базовый шрифт шкалы: **Montserrat**. Веб-версия гайда с иллюстрациями: `typography/index.html`.

---

## 1. Основные принципы

### Line Height кратен 4px

Никаких `120%`, `Auto` и дробных значений. Все LH — чётные значения, кратные 4px,
чтобы идеально ложиться в 4px grid.

**Пример (Body / M, LH 24px):**

```
┌─ 4px grid ─────────────────────────────┐
│ Body / M — line-height 24px            │  ← 6 единиц сетки
│ Следующая строка на 24px ниже          │
└────────────────────────────────────────┘
```

**Блокер:** `line-height: 120%`, `line-height: Auto`, любые дробные LH.

### Имена по ролям, а не по тегам

Не `H1/H2`, а `Heading / L`, `Body / M`, `Label / S`.
Разработчики мапят это на теги, стили SwiftUI/Compose и т.д.

| ✕ Не использовать | ✓ Использовать |
|---|---|
| H1 · H2 · H3 | Heading / XL · Heading / L · Heading / M |
| paragraph · caption | Body / M · Body / S |
| button-text | Label / M · Label / L |

### Body ≠ Label

| Роль | Назначение | Режим |
|---|---|---|
| **Body** | Текст для чтения | 2+ строки, высокий LH, paragraph-режим |
| **Label** | Текст для управления | Кнопки, инпуты, чипы, табы; однострочный режим |

**Пример Body / M** — абзац в карточке или описании (многострочный).

**Пример Label / M** — текст на кнопке «Продолжить», в чипе «Фильтр», в пункте меню.

## 2. Мобильная шкала стилей (Montserrat, Mobile)

Базовая единица LH: **4px**.
Шкала балансирует читаемость и экономию вертикального пространства.

Иерархия категорий:

```
Display  →  редкие акцентные экраны (онбординг, paywall)
Heading  →  заголовки UI (1–2 строки)
Body     →  текст для чтения
Label    →  текст на контролах
```

### Display

Акцентные — редкие, для онбординга/paywall.

> Не рекомендуется использовать внутри обычных скролл-экранов с контентом и формами.

| Стиль | Size | LH | Weight | Letter Spacing | Назначение |
|-------|------|----|--------|----------------|------------|
| Display / M | 36 | 44 | 700 | -0.5px | Крупный акцентный заголовок |
| Display / S | 32 | 40 | 700 | -0.3px | Welcome-экраны, success-экраны |

**Пример (Display / S — welcome-экран):**

```
┌─────────────────────────┐
│                         │
│   Добро пожаловать      │  ← Display / S, 32/40, Bold
│                         │
│   Краткое описание      │  ← Body / M
│   сервиса               │
│                         │
│   [ Начать ]            │  ← Label / L
└─────────────────────────┘
```

### Heading

Заголовки мобильного интерфейса. Оптимизированы под 1–2 строки.
Если уходит в 3+ строки — снижай уровень или сокращай текст.

| Стиль | Size | LH | Weight | Letter Spacing | Назначение |
|-------|------|----|--------|----------------|------------|
| Heading / XL | 28 | 36 | 700 | -0.2px | Large Title (экран/секция) |
| Heading / L | 24 | 32 | 700 | -0.1px | Заголовок Bottom Sheet / Dialog |
| Heading / M | 20 | 28 | 600 | 0px | Стандартный заголовок экрана/секции |
| Heading / S | 16 | 24 | 600 | 0px | Заголовок карточки, айтема списка |
| Heading / XS | 14 | 20 | 600 | +0.1px | Подзаголовки, мини-блоки |

**Лестница иерархии:**

```
Heading / XL  (28px) — Заголовок экрана
Heading / L   (24px) — Bottom Sheet / Dialog
Heading / M   (20px) — Секция
Heading / S   (16px) — Карточка, list item
Heading / XS  (14px) — Мини-блок
```

### Body

Текст для чтения на мобиле.

| Стиль | Size | LH | Weight | Letter Spacing | Назначение |
|-------|------|----|--------|----------------|------------|
| Body / L | 16 | 28 | 500 | 0px | Важные короткие описания, вводные |
| Body / M | 14 | 24 | 500 | 0px | Основной текст в приложении |
| Body / S | 12 | 20 | 500 | +0.2px | Сноски, дисклеймеры, подсказки |

### Label

До двух строк, Paragraph Spacing = 0.

| Стиль | Size | LH | Weight | Letter Spacing | Назначение |
|-------|------|----|--------|----------------|------------|
| Label / L | 16 | 24 | 600 | 0px | Buttons, крупные инпуты |
| Label / M | 14 | 20 | 600 | 0px | Buttons, чипы, меню |
| Label / S | 12 | 16 | 600 | +0.2px | Бейджи, короткие подписи к UI |
| Label / XS | 10 | 12 | 600 | +0.3px | Подписи в Tab Bar, микро-лейблы |

## 3. Шрифтовые пары

Готовые сочетания стилей и отступов (Stack) для типовых UI-паттернов.

### Пара 1. Экран с Large Title

```
Heading / XL (28px) — Заголовок экрана
↓ Stack / MD (16px)
Body / M (14px) — Краткое описание
```

```
┌─────────────────────────┐
│ 9:41                    │
│                         │
│  Заголовок экрана       │  Heading / XL
│                         │  ↕ 16px
│  Краткое описание       │  Body / M
│  раздела                │
└─────────────────────────┘
```

### Пара 2. Карточка / List Item

```
Heading / S (16px) — Название
↓ Stack / XS (4–8px)
Body / S (12px) — Описание (1–2 строки)
```

```
┌─────────────────────────┐
│ ┌─────────────────────┐ │
│ │ Название услуги     │ │  Heading / S
│ │ ↕ 4–8px             │ │
│ │ Описание в 1–2      │ │  Body / S
│ │ строки              │ │
│ └─────────────────────┘ │
└─────────────────────────┘
```

### Пара 3. Bottom Sheet

```
Heading / L (24px) — Заголовок
↓ Stack / MD (16px)
Body / M (14px) — Описание
↓ Stack / LG (24px)
[Контролы: Label / M и Label / L]
```

```
┌─────────────────────────┐
│        ───              │  handle
│  Подтвердите действие   │  Heading / L
│                         │  ↕ 16px
│  Описание в Body / M    │  Body / M
│                         │  ↕ 24px
│  [ Подтвердить ]        │  Label / L
│  [ Отмена ]             │  Label / M
└─────────────────────────┘
```
