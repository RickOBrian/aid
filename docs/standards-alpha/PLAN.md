# План: стандарты компонентов → альфа 0.1.0

> Обновлено 2026-09-22 · набор `0.1.0-alpha` · реестр: `standards-registry.json`

Цель: превратить черновики стандартов в набор, который можно опубликовать
пользователям и на который потом опираются аудит чужих библиотек,
маппинги, опознавание компонентов, плагины и отрисовка компонентов с нуля.

Ядро альфы (ADR-003): `component-standards`, `ds-component-architecture-guide`,
`component-states-guide`, `naming-conventions`, `platforms`.

Статусы задач: `todo` · `in progress` · `done` · `blocked` · `dropped`

**Состояние на 2026-09-22.** Альфа опубликована и в production. Все восемь

Проверить первым делом:

```bash
git status --short                       # должно быть пусто
node scripts/check-docs.mjs              # 0 ошибок, 0 предупреждений
gh pr list --repo RickOBrian/aid --state open
```

**Что может быть в полёте.** На момент записи открыт один наш PR — он
закрывает Q-16 и добавляет ADR-035. Если его нет в списке открытых, он
смержен; если есть — его мерж и есть ближайший шаг.

Очередь предложений от плагина пуста: #14 смержен, #1, #9, #10 и #11
закрыты (ADR-035). Всё, что появится в `registry/propose-*` дальше, —
свежие предложения, а не завал.

**Следующая содержательная задача.** Блокирующих в очереди нет — задачи
ниже берутся в любом порядке.

Раньше здесь стояли пространственные токены `driver` с пометкой
«блокирует». Это было сформулировано неверно: токены и стили продукта
вправе отличаться от стандарта, и приведение их к эталону — отдельная
задача, которая сейчас не в работе (ADR-036).

**Чего не делать без спроса** — `CLAUDE.md`, раздел «Git-полномочия»:
merge в `main`, promote, изменение конфигов Vercel и CI. Разрешение,
данное однажды, на следующий раз не распространяется.

## Волна 3.5 — AID вместо Driver в местах, где driver ≠ продукт · ЗАВЕРШЕНА

Driver — один из продуктов, с теми же правами, что rider. Но в трёх местах
он занял слот, принадлежащий системе (AID), и третий продукт упрётся в это
при онбординге.

`products/driver/` и `changes/driver/` **корректны** — это product-scoped
границы, их не трогаем.

| ID | Слой | Задача | Риск |
|---|---|---|---|
| W35-1 | Идентификаторы | `DriverColorMode` → `ProductColorMode` и подобные, 12+ файлов | done |
| W35-2 | Имена файлов | `tokens/*-changelog.json` без префикса → `driver-*`, симметрично rider | done |
| W35-3 | Директория портала | `pages/aid-portal/` → `pages/aid-portal/`, 75 файлов | done |
| W35-4 | Маршруты | driver: `/design-system` (корень) → `/driver/design-system`; корень отдать AID-хабу | done |

### Когда

**Единым заходом между Волной 3 и Волной 4** — машинный слой готов,
публикации ещё не было.

- Волны 1–3 — только документы, от переименования не зависят;
- портал ещё не оброс кодом рендерера гайдов (W4-1);
- маршруты меняются **до** того, как ссылки на гайды уйдут людям;
- одно окно деплоя, одна правка настройки Vercel, одна проверка Preview.

Исключение: **W35-1 можно раньше** — ничего не ломает, а Волна 1 пишет про
режимы Day/Night и лучше ссылаться на уже правильное имя.

### Операционное условие для W35-3

Переименование директории требует одновременной правки Root Directory в
Vercel. Пока пути расходятся, Preview падает. Делать в окно, где нет других
открытых PR по порталу, и менять настройку в ту же сессию. Естественно
совместить с висящим решением о promote в production.
