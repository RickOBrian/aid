Typography

Live-редактор типографических токенов docs/guides. Изменения применяются при потере фокуса поля (blur); сохранение записывает значения в файлы репозитория.

Сохранение недоступно на этом сервере. Запустите python3 scripts/docs-server.py или в отдельном терминале node docs/tokens/save-tokens.js --serve.
