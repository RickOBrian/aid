Уровень архитектуры

Требует уточнения (перепроверено). card__header, card__description, card__footer — это BEM-классы CSS для стилизации визуально разных зон блока, а не именованные слоты как API (нет пропсов/@ViewBuilder/lambda-параметров, которые описаны в разделе 9 гайда). В этом репозитории нет реализации компонента на целевой платформе, которая подтвердила бы slot-контракт — только статичная разметка одного инстанса. По одному лишь CSS нельзя отличить «Structural View с 3 слотами» от «Surface View с внутренней вёрсткой»: понижаю до «требует уточнения» до подтверждения на уровне реализации компонента.

Нарушения

Не найдены — все значения ссылаются на semantic-токены.

Confidence

low — спорно; нет подтверждённого named-slot API, только CSS BEM-конвенция.
