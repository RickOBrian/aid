Structural View — два и более именованных слота (заголовок + повторяющиеся строки), см. ds-component-architecture-guide.md, раздел «Repeatable Slot / Cell Span» (v1.3.0).

Слоты

header
опциональный, <thead>.
content
repeatable, <tbody>: каждая <tr> — экземпляр TableRow.

⚠️ TableRow (spec-003) — stage: draft, open_questions: 1: контракт слота content считать предварительным до перевода в final.

Варианты

Static
статичная разметка (docs/storybook/typography.html, docs/storybook/colors.html).
Interactive-generated
строки рендерятся JS-шаблоном (docs/storybook/typography-editor.js, docs/storybook/colors-editor.js) — mapping для этой группы ещё не решён (memory/ds-component-migration/log.*.json, migration-001).
Row-level: is-clickable
hover-состояние строки уже есть в CSS (bg-accent-states-hover), но именованный контракт на уровне TableRow для него — draft, не финализирован.
