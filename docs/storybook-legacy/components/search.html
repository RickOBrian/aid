FieldSearch

Surface View medium

Карточка компонента с editable-слоем: component-side значения редактируются на месте (typed dropdown для токенов, инлайн — для прямых значений).

Preview

Уровень архитектуры

Surface View — подтверждено Principal Designer. Состав компонента — Icon (Item-примитив, декоративный) + Input (Item-примитив, аналогичный Text/Number), ни один элемент не является самостоятельным Role/Entity-компонентом → критерий ds-component-spec/SKILL.md (Шаг 2, v1.3.0) даёт Surface View. Компонент переименован в FieldSearch (конвенция полей ввода — префикс Field*, как у FieldCheckbox/FieldRadio). Открытый вопрос остаётся только по обязательности leading-иконки — в репозитории нет реализации, которая подтвердила бы это по коду.

Нарушения

  • Gap

    padding-left: 36px (отступ под иконку) — захардкожен, semantic-токен под отступ иконки в контроле не заведён, нужно предложить новый.

  • Quality note

    width: 280px на контейнере — захардкожен, но это ширина конкретного инстанса в шапке сайта, а не переиспользуемое значение стиля; ограничение метода анализа (только один инстанс использования в разметке).

Confidence

medium — уровень подтверждён Principal Designer; открыт только вопрос обязательности leading-иконки (нет реализации для проверки по коду).
