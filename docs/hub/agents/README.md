# Карточки ролей и чатов

ADR-047, ADR-048, `../ORCHESTRATION.md` §11. Карточка роли (`tasks.md`,
`qa.md`…) — одна на роль, одинаковая у всех живых инженеров. Чат может
вести несколько ролей — у такого чата своя карточка: `ops.md` (Tasks,
Team, Requests), `review.md` (QA, Security). Состав чатов — корневой
`CLAUDE.md` «Роли и чаты» (решение PD 2026-10-18). Карточка публичная: без
имён, контактов и секретов.

Форма карточки: чат, папка, зона, делает сам, не делает никогда, вход в
контекст, с кем стыкуется. Правка карточки — PR через Штаб PD.
