# Карточки ролей и чатов

ADR-047, ADR-048, `../ORCHESTRATION.md` §11. Карточка роли (`tasks.md`,
`qa.md`…) — одна на роль, одинаковая у всех живых инженеров. Чат может
вести несколько ролей — у такого чата своя карточка: `ops.md` (Tasks,
Team, Requests), `review.md` (QA, Security). Состав чатов — корневой
`CLAUDE.md` «Роли и чаты» (решение PD 2026-10-18). Карточка публичная: без
имён, контактов и секретов.

Форма карточки: чат, папка, зона, делает сам, не делает никогда, вход в
контекст, скиллы по моментам, с кем стыкуется. Правка карточки — PR через
Штаб PD.

## Скиллы: момент → скилл

AID-114 (issue #646). Скилл зовут, когда наступил момент из таблицы, а не
по памяти. Вызов — инструментом Skill (`/имя`); скилла нет в списке Skill —
прочитать `skills/<имя>/SKILL.md` (или `.claude/skills/<имя>/SKILL.md`) и
выполнить, а в итоге задачи написать, что список устарел (папка не
обновлена от `origin/main`, «Подключение» ниже). Колонка «Жёстко» — без
скилла следующий шаг не делается, это проверяет другой чат или скрипт.

Скрипты в тех же моментах:

| Момент | Команда | Кто | Жёстко |
|---|---|---|---|
| Перед PR, который трогает документы, скиллы, карточки, доску | `node scripts/check-docs.mjs` | все чаты | да: CI «Документы» и `merge-precheck` останавливают PR с ошибками |
| Перед каждым мержем в `main` | `node scripts/merge-precheck.mjs <N>` | Merge; автор, который мержит сам | да: Merge без отчёта «можно мержить» не мержит |

Новый скилл в `skills/` или `.claude/skills/` попадает в эту таблицу тем
же PR: `check-docs` ищет имя каждого скилла здесь (правило
`skill-trigger`).

### Подключение

Инструмент Skill видит только `.claude/skills/` папки чата. Скиллы из
`skills/` подключены туда симлинками `.claude/skills/<имя>` →
`../../skills/<имя>` (AID-114); `check-docs` следит, чтобы у каждого
скилла `skills/<имя>/SKILL.md` был симлинк (правило `skill-link`).

Папка чата получает скиллы, когда её ветка начата от свежего
`origin/main` (или в неё влит `origin/main`), список Skill — при старте
сессии: после обновления папки — перезапуск. Чаты под задачу (Designer,
Developer) открываются в worktree от `origin/main` и получают скиллы
сразу. Пометка «по команде» в таблице — скилл зовёт только человек: у
`ds-component-audit` стоит `disable-model-invocation: true` (в списке
Skill его нет), `ds-component-migration` по своему описанию активируется
строго по команде.
