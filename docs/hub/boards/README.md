# Доски Штабов инженеров

У каждого инженера AID — свой «AID · Hub · Штаб» (`../ORCHESTRATION.md` §9)
и своя доска здесь: `<код>.md`, задачи `AID-<КОД>-<n>`. Код — 1–3 буквы по
роли, без имён (репозиторий публичный). Форма доски —
`../kit/BOARD.template.md`.

Главная доска — `../BOARD.md` (Штаб Principal Designer, задачи `AID-<n>`).
Запросы между Штабами — GitHub Issues с меткой `hub`, а не правки чужой
доски: каждый Штаб правит только свой файл.
