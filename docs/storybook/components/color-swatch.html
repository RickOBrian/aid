Read-only карточка компонента — без controls для редактирования.

ColorSwatch

требует уточнения
Уровень Требует уточнения. Базовый вариант (.color-swatch) — атомарный цветной блок без вложенного контента, по аналогии с Dot (Item, раздел 4). Alpha-вариант (.color-swatch--alpha) состоит из двух визуальных частей (solid + alpha-заливка) — граница Item/Structural View неочевидна, критерий «именованный слот» здесь чисто визуальный, не контентный.
Confidence low — спорно, классификация уровня требует уточнения у Principal Designer.
Semantic-токены, найденные в локальном stylesheet layer компонента radius-s line-default bg-base-main-secondary
Нарушения ⚠️ Blocker — .color-swatch__checker использует захардкоженные HEX (#ccc, #ffffff) в background-image / background-color — прямое нарушение no-hardcode-color-protocol.
⚠️ Gap — width / height (32px, 64px) — захардкожен размер; semantic size-токена для габаритов свотча не существует, нужно предложить новый.
