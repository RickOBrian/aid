Search (FieldSearch)

требует уточнения
Уровень Требует уточнения (перепроверено). search__icon и search__input — BEM-классы CSS, а не именованные слоты как API: в разметке это два самостоятельных потомка .search, без компонента с пропсами/@ViewBuilder/lambda-параметрами leading/ content из раздела 9. Визуально структура похожа на Field-компонент, но в этом репозитории нет реализации, которая подтвердила бы slot-контракт — только один статичный инстанс разметки: понижаю до «требует уточнения» до подтверждения на уровне реализации компонента.
Confidence low — спорно; нет подтверждённого named-slot API, только CSS BEM-конвенция.
Semantic-токены, найденные в локальном stylesheet layer компонента inset-control-v-s inset-control-h-m radius-m line-default line-accent bg-base-main-secondary bg-card-main text-primary text-disabled icon-secondary label-s-size label-s-lh label-s-weight
Нарушения ⚠️ Gap — padding-left: 36px (отступ под иконку) — захардкожен, semantic-токен под отступ иконки в контроле не заведён, нужно предложить новый.
⚠️ Quality note — width: 280px на контейнере — захардкожен, но это ширина конкретного инстанса в шапке сайта, а не переиспользуемое значение стиля; ограничение метода анализа (только один инстанс использования в разметке).
