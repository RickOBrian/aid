Search (FieldSearch)

требует уточнения low

Карточка компонента с editable-слоем: component-side значения редактируются на месте (typed dropdown для токенов, инлайн — для прямых значений).

Preview

Уровень архитектуры

Требует уточнения (перепроверено). search__icon и search__input — BEM-классы CSS, а не именованные слоты как API: в разметке это два самостоятельных потомка .search, без компонента с пропсами/@ViewBuilder/lambda-параметрами leading/ content из раздела 9. Визуально структура похожа на Field-компонент, но в этом репозитории нет реализации, которая подтвердила бы slot-контракт — только один статичный инстанс разметки: понижаю до «требует уточнения» до подтверждения на уровне реализации компонента.

Нарушения

  • Gap

    padding-left: 36px (отступ под иконку) — захардкожен, semantic-токен под отступ иконки в контроле не заведён, нужно предложить новый.

  • Quality note

    width: 280px на контейнере — захардкожен, но это ширина конкретного инстанса в шапке сайта, а не переиспользуемое значение стиля; ограничение метода анализа (только один инстанс использования в разметке).

Confidence

low — спорно; нет подтверждённого named-slot API, только CSS BEM-конвенция.
