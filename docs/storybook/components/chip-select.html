Уровень архитектуры

Surface View — один контент-элемент (текст) в оболочке (фон + форма + отступы) с опциональным вспомогательным элементом (leading icon), без второго именованного слота — см. ds-component-architecture-guide.md (раздел 5, 9).

Нарушения

  • Gap

    filter: brightness(0.94) на :active — pressed-фидбек без токена (semantic-токена для тонального сдвига pressed-состояния solid-фона нет, кроме готовой пары bg-neutral-states-pressed для is-active-фона). Для off-состояния (bordered/tinted) нужен отдельный *-states-pressed-токен на семью neutral/accent — ⚠️ нужно добавить токен: bg-accent-states-pressed уже есть и переиспользован для fade-accent off, но neutral off-pressed временно на filter-эффекте.

Confidence

medium — структура и уровень подтверждены прямым примером Surface View (иконка как вспомогательный элемент, без второго слота), но source of truth — Figma-фрейм (превью нескольких инстансов), не сам master-компонент/component-set; appearance-цвета подобраны по существующим semantic-токенам, а не сняты пиксель в пиксель с оригинала (Figma здесь — референс структуры/вариантов, не источник значений).
