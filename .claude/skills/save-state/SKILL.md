# save-state — состояние в CLAUDE.local.md и перезапуск

Правило — `docs/hub/ORCHESTRATION.md` §12 «Короткий контекст»: порог
перезапуска любого чата — 150 тыс. токенов; задача закрыта — состояние в
`CLAUDE.local.md` своей папки (не в git), затем `clear_session("self")`.
Напоминает хук `.claude/hooks/context-guard.py`. Отвечать по-русски.

## 1. Безопасная точка

Перед записью довести текущий шаг до места, с которого его можно
продолжить без памяти чата:

- правки закоммичены и запушены в свою ветку (незакоммиченное после
  очистки никто не вспомнит);
- начатое сообщение другому чату — отправлено или записано как «не
  отправлено, ждёт …»;
- подагенты — дождаться итога или записать их id и что они делают.

Задача почти закрыта — сначала закрыть, потом записывать.

## 2. Записать

Файл — `CLAUDE.local.md` в папке чата (корень worktree). Не в git, другие
чаты его не видят. Правила в него не писать: правило — сразу в
репозиторий (карточка роли, гайд), здесь — только состояние.

Раздел «СЛЕДУЮЩЕЕ» — в начало файла, старое состояние ниже не стирать, а
сжимать: закрытое — одной строкой «✅ <дата> <что> — <PR/итог>».

```
## СЛЕДУЮЩЕЕ (<ГГГГ-ММ-ДД>, перед перезапуском) — начать отсюда

**Задача:** AID-<n> <имя>, issue #<n>, ветка <ветка>, PR #<n> (<состояние: CI, ревью, мерж>).
**Сделано:** <факты, коротко; коммит/PR>.
**Ждёт:** <кого и чего: «да» PD на …, ответ чата <имя> (local_…), мерж Merge>.
**Дальше:** <первое действие после перезапуска — одной фразой, конкретно>.
**Не отправлено:** <черновики сообщений и вердиктов, кому, по чьему слову отправлять>.
**Id:** <узлы Figma, id чатов local_…, id подагентов — то, что не найти поиском>.
**Решения PD по задаче:** <дата, дословно, где дано; или ссылка на строку «Решения PD»>.
```

- Даты — абсолютные (`2026-11-25`), не «вчера» и не «в четверг».
- Цитаты PD — дословно; пересказ помечать «моё».
- Большие черновики — файлом в папке заметок сессии или в ветке, в
  `CLAUDE.local.md` — путь к нему.
- Не писать секреты, ключи, токены — даже в локальный файл.

## 3. Проверить запись

Перечитать только что записанный раздел глазами нового чата: хватает ли
его, чтобы продолжить, не читая историю. Не хватает — дописать.

## 4. Перезапуск

`clear_session("self")`. После перезапуска чат по «старт» читает только
`CLAUDE.local.md` и карточку роли (§12 «Лёгкий старт»), остальное — по
задаче нужным разделом.

## Запреты

- Не очищать контекст с незакоммиченной работой и неотправленным без
  записи.
- Не переносить в `CLAUDE.local.md` правила и решения, которых нет в
  репозитории, как будто они действуют для всех: правило — PR в репо.
