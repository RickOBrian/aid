# Визуальный язык Persefona

> Статус: Alpha · v1.0.0 · обновлено 2026-10-23

---

## 1. Назначение

Persefona — UI Kit самого AID (`products/persefona/product.json`): служебные
страницы Figma, интерфейс Presentbook, гайды и чейнжлоги, плагины. Этот
документ закрепляет правила вида, принятые в арт-директорском проходе
persefona-1 (`changes/persefona-1-art-direction-2026-10-23.md`):
решение Standards · Persefona 1б · 2б · 3а · 4а и решение PD 2026-10-23,
согласовавшее все предложения Designer · Persefona (BOARD «Решения PD»).

Канон значений — переменные и стили библиотеки Figma Persefona
(`YDjPxFrW1yXqm9RzBGQXuc`, коллекции `persefona-core` и
`persefona-semantic`) и их запись в `changes/persefona/pending/`. Таблицы
значений здесь не повторяются: документ отвечает на вопрос «по какому
правилу», а не «какой HEX». Исключение — значения, которые сами являются
решением PD (§3.2).

Новое значение или отход от правила ниже — пачкой по
`persefona-kit-improvement.md`.

## 3. Цвет: нейтрали

### 3.1. Одна температура

Все ступени `graphite` — одна шкала одного тона: H ≈ 290 (OKLCH),
насыщенность 0.002–0.008. Серый остаётся серым, но принадлежит одному
семейству с цветным акцентом iolite.

- Новая нейтральная ступень заводится в той же шкале: тот же тон, та же
  полоса насыщенности, светлота — по номеру ступени.
- Значение «чистого серого» (C = 0) или холодного сине-серого из кода
  портала в Kit не переносится — оно приводится к шкале.
- `graphite-100` — чистый чёрный (ступень 100 по `core-color-tokens-guide`);
  прозрачности для теней — `graphite-100-a<N>`.

### 3.2. Акцент

- Основной акцент — графит: `graphite-70` = `#2C2C2F` (решение PD
  2026-10-23; прежнее `#2D2C2E` приведено к шкале).
- Цветной акцент — iolite (`iolite-55` = `#6A1FD0`) и производные; только для бейджей
  `vivid` и `vivid-soft`. Хром портала остаётся без цвета продукта (PD,
  п. 9 #354).

Оба значения меняются только ответом PD (`persefona-kit-improvement` §5).

### 3.3. Вторичный текст

`text-secondary` проходит AA (4.5:1) на всех трёх поверхностях —
`bg-surface-main`, `bg-surface-muted` и `bg-surface-zebra`. Обходы вида «на приглушённом
фоне подпись — `text-primary`» не нужны и не заводятся.

## 4. Цвет: статусы и бейджи

### 4.1. Одно семейство

Статусы (`malachite`, `amber`, `garnet`, `lapis`) равны по весу: глаз
читает смысл по тону, а не по яркости.

- Текст статуса — одна светлота: L 0.50, насыщенность до 0.15 (у зелёного
  и жёлтого — до предела sRGB).
- Фон статуса — одна светлота и насыщенность: L 0.965, C 0.022.
- Жёлтый — янтарный (тон ≈ 70), не оливковый.
- Ступень в имени — по светлоте: текст статусов — `-50`, фон — `-5`
  (поэтому `amber-45` переименован в `amber-50`).
- Текст статуса на своём фоне — не ниже 4.5:1.

Новый статус заводится по этим же числам, а не подбором «на глаз».

### 4.2. Бейджи

- Мягкий бейдж (статусы, `vivid-soft`) — **два слоя: фон и текст**, без
  рамки. Фон уже отделяет бейдж от поверхности.
- Рамка — только у нейтрального бейджа: на `bg-surface-muted` его фон
  сливается с поверхностью. Токен — `line-accent-status-neutral`.
- Токены рамок для цветных бейджей (`line-accent-status-success`,
  `-warning`, `-error`, `-info`, `line-accent-vivid`) удалены и заново не
  заводятся. Понадобится рамка для другой задачи (плашка-уведомление) —
  новым токеном по её смыслу, пачкой.

## 5. Типографика

### 5.1. Гарнитура и веса

- Текст — Google Sans (PD 5а), код — Google Sans Code.
- Веса — только **400 и 500**. У Google Sans нет начертания 600:
  `type-weight-600` не заводится, «полужирный» не имитируется.
- Код — вес 400: моно с крупным глазом при 500 выглядит жирнее текста.

### 5.2. Шкала и иерархия

Размеры — `11, 12, 13, 14, 16, 20, 32, 48`; интерлиньяж — `16, 20, 22,
24, 28, 40, 56`. Промежуточные размеры (18, 28 и т. п.) не используются.

Иерархия страницы держится размером, а не весом, и у страницы всегда
есть главное:

| Уровень              | Стиль        | Размер · интерлиньяж |
|----------------------|--------------|----------------------|
| Обложка              | `display-l`  | 48 / 56              |
| Раздел               | `heading-l`  | 32 / 40              |
| Подраздел            | `heading-m`  | 20 / 28              |
| Заголовок блока      | `heading-s`  | 16 / 24              |
| Основной текст       | `body-m`     | 14 / 22              |

- Заголовок обложки — всегда `display-l`; два соседних уровня одного
  размера не бывают.
- `body-m` 14/22 — для страниц чтения (гайды, changelog, аудит); 13 —
  только `body-s` и `code-m`.

### 5.3. Трекинг

Трекинг в Figma — в px, округление до десятых; токены
`type-tracking-<значение>` (`--1`, `--0_3`, `0`, `0_6`). Крупные
заголовки — отрицательный трекинг (`display-l` −1, `heading-l` −0.3),
подпись капсом — `0_6`, остальное — 0.

## 6. Глубина и фокус

### 6.1. Тени

Тень — **два слоя**: плотная контактная (где элемент касается
поверхности) и широкая (насколько он поднят). Однослойная размытая тень
не используется.

- Цвет теней — только прозрачности `graphite-100-a<N>`, не чистый чёрный
  литералом.
- Два уровня подъёма: `shadow-1` и `shadow-2`. Третий уровень — пачкой,
  с той же двухслойной схемой.

### 6.2. Фокус

У каждого фокусируемого элемента Kit — видимое кольцо фокуса (WCAG 2.4.7):

- кольцо 2 px с зазором 2 px цвета поверхности;
- цвет — `line-focus` (→ `graphite-70`); на `bg-inverse-main` —
  `line-focus-inverse` (→ `graphite-0`);
- нетекстовый контраст кольца к соседнему цвету — не ниже 3:1
  (WCAG 1.4.11); для новой поверхности проверяется до сборки.

## 7. Что не меняется

- Сетка отступов — 4; радиусы — 4 / 8 / 12 / 16 / pill, вложенные блоки
  концентричны (PD 2а).
- Только светлая тема (PD 6а).
- Акцент и шрифт — §3.2, §5.1.

## 8. Проверка

Перед приёмкой токена, стиля или блока Persefona:

- [ ] новая нейтраль — в шкале `graphite` (тон ≈ 290, C 0.002–0.008);
- [ ] новый статус — текст L 0.50, фон L 0.965 / C 0.022, 4.5:1 на своём фоне;
- [ ] мягкий бейдж без рамки; рамка только у нейтрального;
- [ ] размер и интерлиньяж — из шкалы §5.2; вес 400 или 500;
- [ ] у страницы есть обложка `display-l`, соседние уровни разного размера;
- [ ] тень двухслойная, цвет — `graphite-100-a<N>`;
- [ ] у фокусируемого элемента есть кольцо, контраст 3:1 на его поверхности;
- [ ] значения привязаны к переменным `persefona-core` / `persefona-semantic`, литералов нет.
