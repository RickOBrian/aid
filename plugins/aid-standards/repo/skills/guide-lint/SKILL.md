# guide-lint

> Статус: Stable · v2.0.0 · обновлено 2026-09-20

Чинит то, что нашёл `scripts/check-docs.mjs`.

---

## 1. Что изменилось в v2.0.0

Раньше скилл содержал чеклист и сам его проверял. Это не работало: за всё
время существования требованиям соответствовали 7 файлов из 40 — проверка,
которую нужно вспомнить и запустить руками, не запускается (ADR-010, 013).

Теперь разделение такое:

| Кто | Что делает |
|---|---|
| `scripts/check-docs.mjs` | Находит: форма, живость ссылок, сходимость версий, дубли имён, расхождение с реестром, легаси-пути |
| `scripts/sync-registry.mjs` | Подтягивает в реестр фактические версии и статусы из файлов |
| Этот скилл | Правит то, что требует суждения: переписать текст под форму, выбрать правильный путь у битой ссылки, решить судьбу устаревшего раздела |

Чеклист из этого файла удалён: он дублировал бы правила скрипта и
разошёлся бы с ними. Форма документа — в
`skills/_shared/protocols/guide-template.md`.

---

## 2. Параметры запуска

- без уточнения → работать по всему отчёту
- `имя-файла.md` → только этот файл
- `--dry-run` → показать план правок, ничего не менять
- `--auto` → не спрашивать по каждому файлу

---

## 3. Процедура

**Шаг 1.** Получить отчёт:

```bash
node scripts/check-docs.mjs --warnings
```

**Шаг 2.** Разделить находки на три группы:

| Группа | Признак | Действие |
|---|---|---|
| Механические | Нет строки статуса, нет нумерации, нет changelog, поля frontmatter | Править сразу |
| Требующие решения | Битая ссылка, устаревший раздел, расхождение терминов | Показать варианты, спросить |
| Не относящиеся к форме | Содержание устарело по существу | Не трогать, вынести в отчёт отдельным списком |

Третья группа — важная. Скилл приводит документ к форме, а не
переписывает его смысл. Устаревшее содержание — это задача волны, а не
линтера.

**Шаг 3.** Править по одному файлу. Для каждого:

1. привести форму по `guide-template.md`;
2. поднять patch-версию (`1.2.0` → `1.2.1`);
3. дописать запись в Changelog первой строкой:
   `- **X.Y.Z** — YYYY-MM-DD. guide-lint: нормализация формы.`
4. если в файле появились или изменились поля `version`, `status`, `kind` —
   выполнить `node scripts/sync-registry.mjs`.

**Шаг 4.** Перепроверить:

```bash
node scripts/check-docs.mjs
```

Ошибок должно стать ноль. Если нет — не коммитить.

**Шаг 5.** Коммит на каждый файл отдельно:

```
chore(guide-lint): normalize <имя-файла> → vX.Y.Z
```

Не объединять несколько файлов в один коммит.

---

## 4. Что запрещено трогать

- содержание разделов: объяснения, примеры, обоснования;
- значения в таблицах — разрешено только выравнивание;
- существующие записи Changelog;
- примеры токенов и их значения;
- блоки «Почему так» — они часть содержания, а не оформления.
