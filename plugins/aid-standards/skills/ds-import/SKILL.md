# DS Import

> Статус: Stable · v2.0.0 · обновлено 2026-09-20

Импорт файлов из `~/Desktop/ds-import/` в репозиторий.

Триггер: пользователь пишет «импорт», «import» или «ds-import».

---

## Что изменилось в v2.0.0

Правило переехало из `skills/ds-import/SKILL.md` и приведено к текущей
раскладке репозитория. Существенные отличия:

1. **Раскладка по жанрам.** `destination` больше не может быть просто
   `skills/_shared/` — нужен жанр: `standards/`, `protocols/`,
   `architecture/` или `notes/`. Файл без жанра требует уточнения наравне
   с файлом без `destination`.
2. **Обязательные поля.** Импортируемый документ обязан иметь `name`
   (совпадает с именем файла), `metadata.version` и `metadata.kind`.
   Не хватает — спросить, не угадывать.
3. **Проверка версий при конфликте.** Если файл уже существует — сравнить
   `metadata.version` обеих редакций и показать разницу. Импорт более
   старой версии поверх новой — стоп по умолчанию.
   Исторически именно так в репозиторий попали устаревшие дубли
   (см. `.cursor/audit-2026-09-17.md`).
4. **После импорта — `node scripts/check-docs.mjs`.** Ошибки — стоп,
   не коммитить.
5. **Реестр.** Новый документ жанра `standard` дописывается в
   `standards-registry.json`.
6. `PROJECT_STRUCTURE.md` больше вручную не правится.

## Алгоритм

### Шаг 0. Проверить git
```bash
cd ~/Projects/aid
git status --porcelain
```
Если есть незакоммиченные изменения — остановиться и сообщить:
"⚠️ Git не чистый. Закоммить или сбрось изменения перед импортом."
Не продолжать.

### Шаг 1. Найти файлы
Найти все .md файлы в ~/Desktop/ds-import/
Если папка пустая — ответить: "ds-import пуста, нечего импортировать" и остановиться.

### Шаг 2. Парсить destination
Для каждого файла прочитать frontmatter и найти поле `destination`.

Пример валидного frontmatter:
```
---
destination: skills/_shared/
---
```

Нормализация пути: если значение destination не заканчивается на `/` — добавить `/`.

Если `destination` есть → запомнить нормализованный путь назначения.
Если `destination` отсутствует → добавить файл в список "требуют уточнения".

### Шаг 3. Уточнить файлы без destination
Если есть файлы без destination — показать список и для каждого спросить:
"Куда положить [имя файла]? (путь относительно ~/Projects/aid/)"
Ждать ответа перед продолжением. Не угадывать самостоятельно.
Применить нормализацию пути к полученному ответу.

### Шаг 4. Проверить конфликты
Для каждого файла:

**4a. Destination в запрещённых папках**
Если destination начинается с `.claude/` или `perplexity-skills/` — предупредить:
"⚠️ [имя файла]: destination указывает на [путь] — это не источник истины.
Источник истины — skills/. Продолжить всё равно?"
Ждать подтверждения.

**4b. Файл уже существует**
Если файл с таким именем уже существует в destination:
- Прочитать `version` из frontmatter обоих файлов.
- Если файлы идентичны → пропустить, не копировать, отметить в отчёте как "без изменений".
- Если входящая версия ниже или равна существующей → предупредить:
  "⚠️ [имя]: входящая версия [X] ≤ существующей [Y]. Перезаписать?"
  Ждать подтверждения.
- Если входящая версия выше → копировать без вопросов.
- Если version отсутствует в одном из файлов → предупредить и спросить подтверждение.

### Шаг 5. Скопировать файлы
Скопировать каждый файл в ~/Projects/aid/[destination][имя файла].
Если папка назначения не существует — создать её.

### Шаг 6. Обновить PROJECT_STRUCTURE.md
Перегенерировать дерево файлов в ~/Projects/aid/PROJECT_STRUCTURE.md:
```bash
cd ~/Projects/aid
tree -a -I '.git|node_modules|.DS_Store' > /tmp/tree-output.txt
```
Вставить вывод в секцию с деревом в PROJECT_STRUCTURE.md, сохранив остальные разделы файла.

### Шаг 7. Коммит
```bash
cd ~/Projects/aid
git add .
git commit -m "chore(import): add [перечислить имена импортированных файлов через запятую]"
git push origin main
```
Если пропущенных файлов больше нет (все были "без изменений") — коммит не делать.

### Шаг 8. Очистить ds-import
Удалить все файлы из ~/Desktop/ds-import/
Папку не удалять — она постоянная.

### Шаг 9. Отчёт
Вывести итог:
✅ Импортировано: [список файлов → пути назначения]
⏭️ Без изменений (пропущено): [список]
🗑️ Очищено из ds-import: [количество] файлов
