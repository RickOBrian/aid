Token Comparator vX.Y.Z
========================

Установка и обновление
----------------------

1. Распакуйте архив и откройте Figma Desktop (импорт через manifest недоступен в браузере без десктоп-клиента).
2. Меню Plugins → Development → Import plugin from manifest…
3. Выберите файл manifest.json из папки token-comparator внутри распакованного архива.

Для обновления до новой версии повторите шаги 2–3 — Figma заменит существующую development-сборку.

Первый запуск
-------------

Откройте вкладку «Настройки» и заполните:

1. Токен доступа Figma — личный токен с правом чтения переменных библиотеки.
2. Файл библиотеки — ссылка на файл Figma или его ключ.
3. Ключ доступа к реестру решений — выдаёт владелец дизайн-системы.

Без третьего пункта плагин работает: сканирование, сравнение и экспорт
доступны. Недоступен только реестр решений — не видно уже принятых решений и
нельзя отправить свои на согласование.
