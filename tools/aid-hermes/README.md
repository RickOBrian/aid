# AID Hermes — сторона AID

Telegram-бот AID Hermes пишет инженерам AID в личку по запросу Штаба PD.
Решение PD 2026-10-26 (`docs/hub/BOARD.md`, «Решения PD»), задача
bot-request-6, AID-73, issue #457.

Hermes — отдельный продукт, не бот заявок (`tools/aid-bot/`): у них разные
владельцы, код и токены.

## Кто и где

| Что | Где |
|---|---|
| Владелец | PD |
| Код, настройки, деплой | приватный репозиторий PD `aid-hermes` |
| Сервер | тот же, где работает бот заявок; отдельный пользователь, папка и процесс |
| Здесь | только контракты: что Штаб отправляет и что получает |

Этот репозиторий публичный: имена, Telegram-ники и id, адреса серверов,
токены и ключи сюда не пишутся. Им место в приватном репозитории.
