## Берём

1. **Зеркальные секции ДО / ПОСЛЕ по потокам** — виден весь поток, глаз
   сравнивает одинаковые места.
2. **Библиотека «как станет»** — одно место, где видна итоговая система.
3. **Маппинг апгрейда** со статусами — готовое ТЗ владельцу библиотеки.
4. **Примеры на элементах** Day / Night со ссылкой на место.
5. **Автоподбор самых изменившихся экранов** для сравнения.
6. **Человеческий гайд** с цифрами и главами.
7. **Выбор токена по контексту поверхности** (глава 08): цвет переднего
   плана выбирается с учётом поверхности, на которой он лежит после
   смены темы — белый текст на постоянно белой карточке в Night — это
   ошибка контекста, а не цвета.

## Не берём — недочёты

| Недочёт | Как у нас |
|---|---|
| **Рекурсивный detach вложенных инстансов** (глава 04: «изменения не сохраняются внутри вложенных экземпляров») — как у агента в Test-3 | Никогда не отвязываем. Цвета и текст внутри инстанса — оверрайды; отступы и радиусы внутри инстанса оверрайдом не меняются — это работа замены компонента (этап 4) или предложение в библиотеку компонентов |
| **Системная клавиатура в Night ПОСЛЕ сломана** (белые клавиши без подписей) | Системные элементы исключены из перевода с самого начала |
| **Токен для клавиатуры** («Display 25 · SF Pro Regular 25», 1 298 исп.) | Системное не токенизируется и не попадает в предложения |
| **Глобальная правка значения ради одного случая** (`space/52 → 56` под safe area) | У предложения — оценка влияния: где ещё используется токен; глобальная правка — только решением владельца библиотеки |
| **Имена новых токенов «по месту»** (`radius/3.5`, `bg/error-surface`) | Имя — по стандарту с учётом соседей в продукте; расхождение со стандартом помечается |
| **Проверка на глаз** — в «ПОСЛЕ» пины иконок, похоже, стали мельче, не отмечено | Регрессии и контраст считаются (этап 3c) |
| **Таблицы — статичный текст**, сделанный один раз | Подача генерируется из данных плагина, пересобирается после правок, ссылается на живые переменные и стили |

## Что это добавляет в движок

- **Контекст поверхности.** Токен переднего плана (текст, иконка)
  выбирается парой с поверхностью под ним: после перевода считается
  контраст пары в каждом режиме темы продукта; не проходит — ищется
  токен, который проходит (inverted, const / static), иначе — «нужно
  решение». Это же ловит «токен вне темы не там»: белый постоянный текст
  на меняющемся фоне.
- **Отступы и радиусы внутри инстансов** не переводятся оверрайдом —
  отмечаются для этапа 4 и в предложения библиотеке компонентов.
