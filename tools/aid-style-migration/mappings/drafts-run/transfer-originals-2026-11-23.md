«Контроль N в мастерах» — у инстансов в копии своё значение (переопределение), а мастер оригинала шёл по правилам;
такие места не переносили (`MASTERS=false`).

Не переносится и остаётся как есть:
- **drift** — в оригинале сырое число не равно значению токена копии (макет правили после копирования): not work 5,
  остальные 0 (после правки 23.11: старый токен → новый с другим значением, например `{Border radius}` 20 → `radius-16`,
  — это наше правило, переносится).
- **noTok** — разница без токена: сырые цвета, чуть отличающиеся в копии (#e5e3ea → #e7e3ea и т. п.; копия при
  клонировании подтянула обновлённые библиотечные компоненты) — Where 3 490, Taxi 672, No car 66, Service 56, GEO 34.
  Не миграция, не трогали.

Особенности скрипта, найденные по ходу:
- Вложенные слои инстансов пересоздаются после правки родителя → пропуск с подсчётом (`gone`), добор повторным
  проходом.
- В Where встречаются «призраки»: слой числится ребёнком инстанса (Cross Medium), но API говорит «не существует»;
  на снимке иконка на месте. Сопоставление такие узлы пропускает.
- Фреймы и группы больше чем с 15 детьми тоже разворачиваются в единицы (Navigation).
- Прогресс хранится «экран, пара внутри» — иначе на больших страницах каждое продолжение заново сопоставляло всю страницу.
- Снятая на копиях тень `[Shadows/Brand button]` переносится (наше правило), хотя в копии токена нет.
- Profile: правилами прошли и 4 новых фрейма «.» (на примерке такие «.» с WB клубом были исключением дизайнера) — глазами.
