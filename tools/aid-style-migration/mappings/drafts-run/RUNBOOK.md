# Прогон страницы — памятка

Правки в Figma — только по «да» arturuxui, только на копиях «<страница> — Switched Styles». Оригиналы не трогать.
Читать только этот файл; `BRIEF.md` — история и клонирование новой страницы. Id копий — `results/LEDGER.md`.

Прогоны идут из самого чата. Агента не заводить: на него уходит ~150 тыс. токенов даже ради одного вызова.
Если страниц много, хватит одного агента на всю очередь, а не агента на страницу.

## Шаги

1. Правила менялись (`migrate-styles.js`, `run-page.js`) — `node scripts/build-kit.mjs`, затем содержимое `upload.js`
   одним вызовом `use_figma` (~10 тыс. токенов, один раз на версию). `fetch` в песочнице нет, иначе не залить.
   Не менялись — шаг пропустить: тело лежит на `figma.root`, версию проверяет HASH.
2. Вызов, повторять без изменений, пока не вернутся строки вместо `{left, of, …}`:
   ```js
   const c="const PAGE_ID='<копия>',DRY=false,HASH=<HASH>;"+figma.root.getSharedPluginData('mig','runner');return await new (Object.getPrototypeOf(async function(){}).constructor)(c)();
   ```
   План, порции, разбитые корни и подсчёт — внутри. 7 400 узлов проходят за один вызов. Обрыв не страшен: вызов продолжит с места.
3. Вернувшиеся строки дописать в конец `results/<slug>.tsv` (`cat >>`). Причин — 60, больше: `TOP=200` до шага 4.
4. Тот же вызов с `CLEAN=true` — снимает план и итог страницы.
5. `node scripts/report.mjs` — обновляет `results/LEDGER.md`. Отчёт руками не писать.

`DRY=true` — только счётчики, узлы не меняются. Сначала DRY по всем страницам, по `LEDGER.md` одна анкета, потом один прогон.
Смена DRY на странице требует `CLEAN=true`. `{error}` с batch — прочитать текст; дважды одно и то же — стоп, спросить.
Конец серии: на `figma.root` очистить ключи `mig` (`body`, `runner`, `hash`), если правила больше не будут меняться.

В `LEDGER.md` «заменено» — с повторного прогона 03.11: первый прогон там не учтён. У старых блоков причины только топ-30.
