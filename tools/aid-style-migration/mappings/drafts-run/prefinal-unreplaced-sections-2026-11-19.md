# Pre-final — секции «Не заменено · <тип>», 2026-11-19

Просьба arturuxui 19.11: справа от секции «Pre-final for Style Switch» `6991:303670` (New Rider Drafts,
стр. «Order Flow ») — секции по типам незаменённого, как «Шрифты вне стилей» `6954:4772` на Switch Audit:
скриншот места с красной плашкой 30 % и ссылки на примеры. Только то, что не заменено в Pre-final.

## Что сделано

- Скан Pre-final — только чтение узлов, `scripts/unreplaced-scan.js`. «Не заменено» — как в `measure-page.js`:
  заливка/обводка не на переменной `color-sem` и не стиль `Gradients/*`; текст без стиля `Bodies/ Subtitles/
  Titles/ Captions/ Outstanding/`; эффект без `Shadows/*`, `Glass/*`. Вне счёта (как в замере): скрытые слои,
  маски, status bar, home indicator, клавиатура, карта, car, логотипы/иллюстрации/пины по имени, ALS Hauss и Factor A.
- Строка — один вид: тип узла (текст/фигура/фрейм) + значение + откуда (без токена / старая переменная /
  старый стиль). Макет — предок, чей родитель — секция.
- Сборка — `scripts/unreplaced-build.js`: шапка, заголовок таблицы и строка — клоны из «Шрифты вне стилей»
  (Kit Persefona). Скриншот — PNG макета, обрезка около места; пример берётся из макета не шире 520 px,
  где место внутри кадра, и не из подписи доски. Справа — счёт по подсекциям Pre-final и ссылки на слои
  (до 12 макетов на строку; текст и вложенный слой инстанса целью ссылки быть не могут — ссылка на ближайший
  фрейм / внешний инстанс, у текста прямо в секции — на подсекцию).
- Подписи доски (текст прямо в секции, фреймы «Подпись · …», «Переход · …», «Условие …») — бейдж «подпись доски»
  или пометка «Из них в подписях доски: N».
- Служебные ключи `pfa` на `figma.root` сняты.
