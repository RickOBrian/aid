## Новые причины пропуска (нет в tsv Drafts)

88 видов / 452 значения. Оговорка: в tsv Drafts у старых блоков лежит только топ причин, поэтому часть «новых» могла
встречаться в Drafts ниже топа. По сути:

1. **Сырые значения без подбора** (~340 знач.) — как и в Drafts, правилом не закрываются: фирменные/иллюстрационные цвета
   (#8626ff 55, #1d364f 45, #d62247, логотипы #fe5f00/#ec001b/#f79e1c, карточки промо #e7f5e9/#2f7d31 и т.п.),
   сырые тени со стеклом на уведомлениях (`drop 3,4 r10 … + glass` — 15+14+…), свечение #9925fe. Анкета не нужна,
   если arturuxui не скажет иначе.
2. **Переменные старых коллекций, которых нет в маппинге** — только на 🔹 Components:
   - `Theme:switch/*` (bg/circle/icon × on/off × default/hovered/pressed/disabled, 24 знач.) — мастер Switch;
   - `Color:tx-notifications/bg-success|bg-error|bg-neutral` (16 / 11 / 8) — плашки уведомлений;
   - `Theme TX:tx-accent/grey/tertiary` [text] 8, `Theme TX:tx-accent/grey/secondary` [shape] 6,
     `Color:tx-accent/orange/fg` [shape] 6, `Color:tx-control/red/bg/pressed` 2, `Theme:text icon/transparent` 1.
   Это кандидаты в анкету (подбор color-sem по смыслу), до боевого прогона мастеров.
3. **Шрифты без стиля на мастерах:** SF Pro Display Bold 34/40 (31), SF Pro Text Semibold 14/110 % (25),
   Google Sans Medium 14/20 CAPS (18), SF Pro Text Regular 14/110 % (3), SF Pro Display Semibold 60 и Regular 22 (по 1).
   Шрифты Валентина заводит отдельно (17.11) — в анкету не берём, список для неё.

Остальные пропуски (`[Background [day]/Secondary]` на shape, сырые блюры, `#c4c4c4`, WB Sans, `tx-brand/green`) — те же,
что в Drafts, решения по ним уже есть.
