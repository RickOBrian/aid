## Запись в tsv и LEDGER

`report.mjs` берёт пропуски и причины из последнего блока страницы (`blocks.at(-1)`), а замены суммирует по блокам с `dry !== '1'`. Поэтому DRY-блок (`dry=1`, строки S без R) дописан в конец каждого `results/<slug>.tsv` (17 файлов), `node scripts/report.mjs` пересобрал `LEDGER.md`. Менять `report.mjs` не нужно. Заменено осталось 49 239 (DRY не засчитан). Строки D в DRY-блоках report не читает.

- Не заменено: было 64 524, стало 59 008; причин в сводке 1 376, хвоста R нет.
- Главная разница — Navigation: 25 489 → 19 492. Старый блок считал экраны «❌ Главная страница», DRY их пропускает.
- Остальные страницы выросли на 1–158 (Where +158, Where - Migration +158, Service coverage +30, test +38, Errors +13, Order Flow +28, Show my location +31): DRY считает текущее состояние копий, блок прогона 12.11 — состояние на момент прогона. Причина (поздние правки того же дня) не разбиралась.
- Копии строк S в tsv: в каждой строке записан один ID (первый), не три — для компактной записи. Колонка ID в LEDGER от этого короче; у Navigation ID пусты у строк с 36-го значения вниз (так отдал сам прогон, видимо лимит на хранение ID).
