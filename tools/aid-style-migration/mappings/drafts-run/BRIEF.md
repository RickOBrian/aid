## Шаги

1. **Дубликат.** Тело `clone-page.js` целиком с первой строкой `const SRC = '<id оригинала>';`.
   Повторный вызов безопасен: если копия уже есть, вернёт её `pageId`.
   **Большая страница** (clone-page.js рвёт соединение MCP или в ней > ~15 000 узлов) — вместо него
   `scripts/clone-roots.js` порциями по ~3 000 узлов: `const SRC = '…'; const FROM = <copied>, TO = …;`
   до `copied === total`. Если `clone-page.js` уже упал — проверить, что копии нет, и идти этим путём.
2. **Разбивка.** Read-only вызов на копии: дети страницы с числом узлов в каждом
   (`n.findAll ? n.findAll().length + 1 : 1`). Набрать порции корней примерно по 1 000 узлов (соединение MCP рвётся на тяжёлых вызовах).
   Корень больше ~1 500 узлов — брать вместо него его детей (ROOTS принимает любые узлы).
   Сами такие корни потом — одним вызовом с `const SHALLOW = true;` (только собственные
   свойства, без детей), иначе их заливки и обводки останутся непройденными.
3. **Прогон.** Для каждой порции — тело `migrate-styles.js` целиком (комментарии в начале можно
   опустить) с первой строкой
   `const DRY = false; const SHOT = false; const PAGE_ID = '<id копии>'; const ROOTS = [...]; const MAXIDS = 50;`
   Порции идут по очереди. Прогон идемпотентен: уже перенесённое пропускается, поэтому
   упавшую по таймауту порцию можно перезапустить (или разбить мельче).
4. **Глазами.** Один скриншот 1–2 экранов копии (`await node.screenshot({scale:0.5})`) —
   убедиться, что вид не развалился. Ничего не исправлять руками.
5. **Отчёт в файл** `tools/aid-style-migration/mappings/drafts-run/<slug>.md` (slug дан в задаче):
   - id оригинала и копии, сколько узлов, сколько порций, были ли ошибки;
   - «Заменено» — сводная таблица `причина → кол-во` (сложить по порциям);
   - «Не заменено» — **полный** список причин `skipped` из всех порций, сложенный по причине:
     `| причина | кол-во | ID узлов (до 50) |`, по убыванию количества. Ни одну причину не
     выкидывать и не обобщать — это список для точечной проработки;
   - `skipByRoot` — сколько пропусков на каждый экран.
   Git не трогать: не коммитить, не переключать ветки.
6. **Ответ** (последнее сообщение): путь к файлу, id копии, число заменённых и незаменённых,
   топ-10 причин незаменённого с количеством, ошибки если были.

Стоп и вернуться с вопросом, если: копия не создаётся, скрипт падает не по таймауту
одинаково дважды, или скриншот показывает поломку вида.

## Экономия контекста (с 2026-11-03, проверено на Where)

Тело скрипта (~7 тыс. токенов) не слать в каждый вызов:

1. Первый вызов — записать тело (минифицированный `migrate-styles.js` без строки параметров)
   в shared pluginData страницы-копии: `page.setSharedPluginData('mig', 'body', <строка>)`.
   Обычный `setPluginData` в use_figma запрещён.
2. Каждый следующий вызов (~300 токенов):
   `const code = "const DRY=false; const SHOT=false; const PAGE_ID='…'; const ROOTS=[…]; const MAXIDS=…;" + page.getSharedPluginData('mig','body');`
   `return await new (Object.getPrototypeOf(async function(){}).constructor)(code)();`
3. В конце прогона — `page.setSharedPluginData('mig','body','')` и проверить, что длина 0.

Вывод порции — сразу в `pNN.json` (Write), итоги — скриптом `agg.js`, не в уме.
Порции ≤10 корней и ≤~3 000 узлов: больше рвёт транспорт. Перед подсчётом узлов — `await page.loadAsync()`.
На копии ничего не создавать и не удалять (кроме ключа pluginData выше).
