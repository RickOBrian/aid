## Главные пробелы (по всем страницам)

- **Градиенты — 0 %:** в маппинге нет, в новой библиотеке нет ни стилей, ни переменных градиентов.
- **Тени — 0–3 %:** почти всё сырое (drop/inner shadow, layer/background blur, glass) или стили вне
  маппинга: `shadow/diffuse/m|s`, `Shadows/Small`, `Shadow S`, `Shadow Up`, `[day] Small`, `Shadow Tabbar`.
- **Токены цвета:** не в маппинге коллекции `Color:tx-*` (grey/tertiary, secondary, light/dark const,
  `control/*/bg/idle`, brand/green), `Theme TX:*`, `theme:icon/*`, `Theme:bg/level 2|-1`, System Colors.
- **Стили цвета:** `[Background [day]/Secondary]` на векторах (правило 1), `[Icons day/Secondary Pressed]`
  на обводке (нет скоупа), `Night / *`, `Gray / 40%`, `Orange/Green/Purple/Blue`, `Fill / Light Grey`,
  `Day / Gray 4|20`, `Texts day/primary 1`.
- **Типографика:** старые семейства `Action/*`, `Description/*`, `Body/body — horse`, `iOS / H2|H4|Subtitle L`,
  сырые SF Pro 12/13, 15/20, WB Sans, ALS Hauss.
- **Отступы/радиусы:** почти всё закрывается расширением «то же значение»; остаток — `Button:Border radius`=18,
  `System:Magin Top`=54, CRx10=40 (нет `radius-18`, `space-54`, `radius-40` в библиотеке).
