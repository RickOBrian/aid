# AID Bot — план

Живой план интеграции бота с продуктами AID. Вопросы, которые блокируют
шаги, — в `OPEN-QUESTIONS.md`.

---

## Роли

Бота развивают параллельно двое, у каждого свой аккаунт Claude. Память
чатов у них не общая, поэтому всё, что должен знать второй, записывается в
репозиторий.

| Кто | Отвечает за | Где работает |
|---|---|---|
| Инженер (автор бота) | Техническая часть: код, хостинг, деплой, хранилище, секреты | Репозиторий бота |
| Principal Designer | Оркестрация: сценарии бота с Figma, плагинами, Presentbook; контракт данных | `tools/aid-bot/` этого репозитория |

Граница между ними — контракт сценария: что бот принимает, что вызывает,
какие данные отдаёт. Его описывает оркестрация, реализует инженер; меняют
только вдвоём. Один репозиторий или два — открыто (Q-02), граница от этого
не зависит.

---

## Принципы

- Плагины Figma (Token Comparator, AID Style Migration) работают только
  внутри клиента Figma, извне их не вызвать. Бот работает с тем, что вокруг
  них: сервер `aid-registry-api`, GitHub (PR `registry/propose-*`,
  релизы), REST API и вебхуки Figma, страницы Presentbook.
- Бот не принимает решений, которые принадлежат людям: не мержит и не
  закрывает `propose-*` (ADR-035), не публикует релизы и не трогает метку
  Latest.
- Стык с продуктом заносится в корневой `CLAUDE.md`, когда появляется на
  деле, — через Principal Designer.

## Шаги

| # | Шаг | Статус | Зависит от |
|---|---|---|---|
| 1 | Обзор бота по ссылке, только чтение: стек, хостинг, модель запросов и задач, хранилище, вебхуки или API | ждёт | Q-01, Q-03 |
| 2 | Инвентарь того, что продукты AID уже отдают наружу: эндпоинты `aid-registry-api`, адреса Presentbook, события GitHub. Только чтение | можно начать | — |
| 3 | Черновик сценариев: кто вызывает, какие данные, чья территория, критерий готовности | ждёт | 1, 2 |
| 4 | Выбор пилота | ждёт | 3 |
| 5 | Контракт пилота — документ, по которому инженер реализует | ждёт | 4, Q-04 |

### Кандидаты в сценарии

| Сценарий | Направление | Что трогает |
|---|---|---|
| Новый PR `registry/propose-*` → уведомление в Telegram со ссылкой | GitHub → бот | только чтение GitHub |
| Релиз плагина → анонс со ссылкой на скачивание | GitHub → бот | только чтение Releases |
| Запрос дизайнера со ссылкой на Figma → задача с превью фрейма | бот → Figma | Figma REST API |
| «Что за токен X» → ссылка на страницу Presentbook | бот → Presentbook | чтение Presentbook |

Предварительно пилот — односторонние уведомления из GitHub (первые два):
только чтение, ни одного нового стыка с продуктами AID.
