# ds-showcase-add

> Статус: Draft · v0.1.0 · обновлено 2026-11-27

Задача persefona-13 / AID-115 (issue #652). Правило —
`products/persefona/rules/persefona-figma-pages.md` §6.10 (ответы PD
дословно — там). Куратор — PD; приёмка — Standards · Persefona.

Применяют исполнитель сборки компонента (Designer · 💠 <Продукт> ·
<Компонент>) и Designer · Persefona (догон). Пока — только Rider
Components (`79UryRdexwKAv8vDIV5v4v`): Driver и Persefona — после
проверки на Rider, отдельным решением PD.

---

## 1. Когда

| Момент | Режим | Кто |
|---|---|---|
| Этап 6: создана страница `🚧 <Компонент> · construction` | `add` | Исполнитель сборки |
| Мастер собран, превью на витрине пустое | `sync` | Исполнитель сборки |
| Значок или имя страницы сменились: 7б (✅), 7б→8 (`readyfordev`), 8 (публикация), переименование компонента | `sync` | Тот, кто переименовал |
| Догон: компоненты, собранные до правила | `sync`, затем `add` на каждый из `missing` | Designer · Persefona |
| Перед запросом приёмки сборки | `persefona-figma-lint`, код L22 | Исполнитель сборки |

## 2. Как запускать

1. Загрузить скилл `figma-use`. Код вызова `use_figma` =
   [`figma-prelude/prelude.js`](../figma-prelude/prelude.js) целиком, затем
   [`showcase.js`](showcase.js) целиком; в `showcase.js` заменить только
   `CONFIG`.
2. **add:** `MODE: 'add'`, `PAGE_ID` — id страницы компонента,
   `CATEGORY` — категория из аудита, строкой из таблицы §2
   `component-categories-guide` (`Navigation`, `Data display: metrics`…).
   Повторный вызов не дублирует: карточка ищется по ссылке на страницу,
   другая категория — карточка переезжает.
3. **sync:** `MODE: 'sync'`. Для каждой страницы сборки, `readyfordev` и
   зоны 2 с карточкой — значок и имя по странице, превью, если пусто,
   порядок по алфавиту. Без карточки — в `missing` (категорию скрипт не
   угадывает); строка в `A–Z`, если есть, обновляется и без карточки. `orphans` — карточки и строки со ссылкой на удалённую
   страницу или страницу не для витрины: скрипт их не удаляет, решает
   исполнитель.
4. Отчёт пользователю — `done`, `warn`, `missing`, `orphans` из ответа.

| Поле `CONFIG` | Значение |
|---|---|
| `MODE` | `add` или `sync` |
| `PAGE_ID` | для `add`: id страницы `PAGE` |
| `CATEGORY` | для `add`: категория `component-categories-guide` §2 |
| `SECTION_GAP` | зазор между секциями, 80 (§6.3) |

## 3. Что скрипт ждёт на странице

Страницу `Showcase` и шаблоны собирает Designer · Persefona один раз по
§6.10 — скрипт их не создаёт и падает с понятной ошибкой, если
чего-то нет.

| Узел | Где | Что внутри |
|---|---|---|
| Секция `By category` | `Showcase` | `HeaderPage`, рамка `Categories` (авто-раскладка), скрытая рамка `_templates` |
| Секция `A–Z` | справа от `By category` | рамка `Index` (авто-раскладка) |
| `Category · _template` | `_templates` | текст `Title`, пустая рамка `Cards` (авто-раскладка с переносом) |
| `Card · _template` | `_templates` | пустая рамка `Preview` фиксированного размера, текст `Name` |
| `Letter · _template` | `_templates` | текст `Letter`, авто-раскладка для строк |
| `Row · _template` | `_templates` | текст `Name` — сам узел или его ребёнок |

Скрипт клонирует шаблоны и меняет только: имена узлов, тексты `Title` (категория),
`Letter` (буква), `Name`, гиперссылку на имени, экземпляр в `Preview`
(вариант по умолчанию, уменьшен до поля), порядок; секции подгоняет под
содержимое и ставит `A–Z` справа верх к верху с зазором 80. Цвета,
стили и отступы — из шаблонов: значений вне Kit скрипт не ставит.


## 4. Правила

- **Внутрь экземпляров** (превью-мастер) скрипт не заходит: `Name`,
  `Preview`, `Cards` ищутся только в своей разметке.
- **Пишет в Figma** только на странице `Showcase`; другие страницы
  читает (имя, мастер для превью).
- **Пустую категорию и пустую букву** скрипт убирает — это его же
  клоны. Карточки и строки не удаляет никогда: `orphans` — в отчёт.
- **Правится только через PR** в `skills/ds-showcase-add/` с новой
  версией в первой строке `showcase.js` и записью в changelog; приёмка —
  Standards · Persefona. Правило §6.10 изменилось — код меняется в том же
  PR или следующим.
- **Проверка** результата — `persefona-figma-lint` L22 (файл): карточка
  и строка у каждого компонента, значок по странице, ссылки живые.
