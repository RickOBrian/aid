## Технические сбои входа

- [ ] Битый/нечитаемый screenshot → вердикт «Cannot analyze input» с причиной, не Ambiguous

## Вердикты

- [ ] Явный существующий компонент (высокое сходство) → Match, компонент назван верно
- [ ] Явно новый компонент (высокий confidence) → New, пройдена проверка naming collision
- [ ] Компонент, непохожий ни на что, но confidence недостаточен для New → Ambiguous, не New
- [ ] Случайный скрин / сторонний сайт → «Not a DS component» с объяснением, без предложения создать/дополнить
- [ ] Match на компонент со статусом Legacy → явное предупреждение «это Legacy, предназначен на замену»
- [ ] Match с ограниченным platform-scope + вход с новой платформой → «Platform scope extension», не state/variant
- [ ] Match с частичным визуальным совпадением (доп. элемент) → явное решение variant/state vs new composite, не автоматическое «дополнить»

## Граничные случаи

- [ ] Два близких Match-кандидата (например Badge/Chip) → двухшаговая проверка: сначала New, затем выбор из существующий A / существующий B / третий новый
- [ ] Единый композитный виджет → вердикт по виджету целиком, вложенные части не получают отдельный полный вердикт
- [ ] Несколько независимых компонентов в одном кадре → вердикт по каждому отдельно
- [ ] Неочевидный тип кадра (композит/несколько) → явный вопрос мне, не решение самостоятельно
- [ ] Компонент микро-уровня без вариантов/состояний → неприменимые шаги пропущены с явным комментарием «шаг N пропущен — ...»
- [ ] Match с дополнением → явно указано «новое состояние» или «новый вариант», не общее «дополнить»
- [ ] Определение платформы неочевидно → показан multi-select с confidence, не угадано молча

## Дедупликация батча

- [ ] Несколько входов → один компонент, без расхождений → одно предложение с перечнем отличий по каждому входу
- [ ] Несколько входов → один вход даёт другой вердикт → вынесен в отдельное предложение
- [ ] Смешанные источники (screenshot + Figma) в одном предложении → source указан для каждого элемента
- [ ] Неочевидно, один ли это компонент → не сгруппировано автоматически, задан вопрос
