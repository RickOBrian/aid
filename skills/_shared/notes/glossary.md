# Словарь терминов

Термин — суть в одну-две строки. Пополняем по ходу работы; источник —
обсуждение с PD.

- **Чекпоинт** — пауза между шагами работы: собираем открытые пункты,
  разбираем их с PD, записываем решения и договорённости; следующий шаг — только
  после этого.
