# figma-prelude

> Статус: Draft · v0.1.0 · обновлено 2026-11-26

Задача persefona-12 / AID-111 (issue #639). Слово PD 2026-11-26 «1, 8, 2,
5 — заводи». Общее для всех Designer; приёмка — Standards.

Каждый чат, который работает в Figma через `use_figma`, заново пишет одни и
те же функции: загрузить шрифты перед правкой текста, достать имя
переменной у заливки, обойти дерево, не провалившись в скрытых детей
экземпляров, вернуть ответ, не превысив лимит. Пишут по-разному и
ошибаются в одном и том же. Сниппет — одно место для этих функций.

---

## 1. Как применять

1. Перед `use_figma` по-прежнему загрузить скилл `figma-use` — прелюдия его
   не заменяет: она даёт функции, а правила Plugin API — там.
2. Прочитать [`prelude.js`](prelude.js) и вставить **целиком** первым
   блоком кода вызова, до своего кода. Между вызовами `use_figma` ничего не
   сохраняется — вставлять в каждый.
3. Свой код — после строки `// ── конец figma-prelude ──`.
4. В брифе подагенту, который будет работать в Figma, — одна строка:
   «Первым блоком кода каждого `use_figma` — `skills/figma-prelude/prelude.js`
   целиком, без правок».

`root.query(sel)`, `.first()` и `node.set(props)` — не публичный Plugin API, а
расширение среды `use_figma` (скилл `figma-use` §5); вне `use_figma` (в
плагине) `one` и `mk` с props не работают.

Прелюдия занимает около 8,5 КБ из 50 000 знаков лимита кода `use_figma`.

Сама прелюдия узлы не меняет: объявляет функции и включает
`figma.skipInvisibleInstanceChildren = true` — обход и `findAll*` не видят
скрытых детей экземпляров (нужны — выключить флаг в своём коде). Пишут в
файл `mk`, `setText`, `bindPaint` и импорт в `varByName`; `toPage`
переключает текущий пейдж — только когда их вызывает ваш код.

**Занятые имена.** Свой `const` или `let` с тем же именем — SyntaxError, и
вызов падает целиком, до выполнения: `byId`, `toPage`, `pageOf`, `one`,
`walk`, `box`, `overlaps`, `h2`, `hex`, `_v`, `vget`, `vname`, `paints`,
`vhex`, `_lib`, `_lv`, `vis`, `varByName`, `bindPaint`, `_s`, `sget`,
`textStyle`, `_f`, `font`, `fonts`, `setText`, `MK`, `mk`, `dump`, `ret`.

## 2. Функции

| Функция | Что делает | Заметки |
|---|---|---|
| `byId(id, type?)` | Узел по id; нет узла или не тот тип — ошибка | Ошибка вместо `null` — правило figma-use 3b |
| `toPage(id)` | Переключиться на пейдж по id | Один раз за вызов — figma-use §2 |
| `pageOf(n)` | Пейдж, в котором лежит узел | — |
| `one(root, sel)` | Ровно один узел по селектору `query`; ноль или больше одного — ошибка с числом | Для правок по имени: не правит «первый попавшийся» |
| `walk(root, fn)` | Обход в глубину по порядку слоёв; `fn(n, depth)` вернул `false` — в детей не заходить | `fn` синхронная (промис не ждётся); детей берёт на момент захода — не удалять узлы по ходу обхода |
| `box(n)`, `overlaps(a, b, gap?)` | Абсолютная рамка; пересекаются ли две рамки с учётом зазора | `absoluteBoundingBox`: без теней и эффектов (для срезов — `absoluteRenderBounds`); у невидимого — `null`, `overlaps` тогда `false` |
| `hex(color, a?)` | `#RRGGBB`, `#RRGGBBAA` — если альфа после округления не `FF` | Принимает цвет заливки и значение переменной |
| `vget(id)`, `vname(id)` | Переменная и её имя по id, с кэшем | Работает и для переменных библиотеки |
| `paints(n, key?)` | Заливки (`fills`) или обводки (`strokes`): `[{type, hex, var}]`; у текста с разными заливками — `'mixed'` | Невидимые пропускает. `var: '?<id>'` — привязка есть, имя не читается (библиотека не подключена): не «голый цвет» |
| `vhex(v, n)` | Значение переменной глазами узла `n` — с его режимами (день, ночь) | `resolveForConsumer`; не COLOR — значение как есть |
| `varByName(name, collection?)` | Переменная по полному имени (`bg/surface/bg-surface-main`) или по последнему сегменту (`bg-surface-main`): сначала в файле, иначе в подключённых библиотеках с импортом | `collection` — имя коллекции, и в файле, и в библиотеке, например `persefona-semantic`. Совпадений не одно — ошибка |
| `bindPaint(n, v, key?)` | Заменить заливки (или обводки) одной заливкой на переменной | Пишет в файл |
| `sget(id)` | Стиль по id, с кэшем | Для `textStyleId`, `effectStyleId` |
| `textStyle(name, root?)` | Текстовый стиль по имени: локальный, иначе применённый на `root` (по умолчанию — текущий пейдж) | Стили библиотеки по имени в API не ищутся — поэтому по применённым |
| `font(f)`, `fonts(root)` | Загрузить шрифт; загрузить все шрифты текстов под `root` | `fonts` вернёт `{texts, missing}` — id текстов с отсутствующим шрифтом |
| `setText(t, s)` | Загрузить шрифты текста и заменить строку | Пишет в файл. При отсутствующем шрифте — ошибка |
| `mk(kind, props, parent?)` | Создать `Frame`, `AutoLayout`, `Text`, `Rectangle`, `Ellipse`, `Line`: сначала в родителя, потом свойства | Пишет в файл. `dir` — направление авто-лейаута; у текста `style` (объект стиля) и `characters`; остальное — через `node.set`. У `Frame` и `AutoLayout` заливка снята — белый по умолчанию был бы сырым цветом |
| `dump(n, depth?)` | Короткое описание узла: id, имя, тип, рамка, заливки и обводки именами переменных или hex, текст и стиль, мастер экземпляра, дети до глубины `depth` (по умолчанию 1) | Глубже — только число детей. Числа узлов не ограничивает: на больших деревьях — `depth` 1–2 и `ret` |
| `ret(o, max?)` | Вернуть `o`, если JSON не длиннее `max` (60 000); иначе ошибка | Не обрезает молча — figma-use 21 |

Пример — правка подписи в секции:

```js
// …prelude.js целиком…
// ── конец figma-prelude ──
await toPage('23:22');
const t = one(await byId('45:74'), 'TEXT[name="Title"]');
await setText(t, 'Colors Core');
return ret({ mutated: [t.id], after: await dump(t, 0) });
```

## 3. Правила

- **Правится только через PR.** Нужна функция или исправление — PR в
  `skills/figma-prelude/` с новой версией в первой строке `prelude.js` и
  записью в changelog; приёмка — Standards. Локальная правленая копия в
  брифе — ровно то, от чего прелюдия избавляет.
- **Совместимость.** Существующие функции не меняют подпись и смысл в
  minor и patch; изменение — major и строка в changelog, кого задевает.
- **Только общее.** Функции, нужные одной проверке или одной задаче,
  живут в её скрипте (`ds-component-check/references/figma-check.js`,
  `persefona-figma-lint`), а не здесь.
- **Без запрещённого `use_figma`:** `loadAllPagesAsync`, `setPluginData`,
  `createImageAsync`, `figma.notify` в прелюдию не попадают.
