## 1. Что сделано на примере Driver

Пример — справочник цветов Driver (131 токен, 10 групп, режимы day/night). Это
макет структуры, а не канон Driver. Данные Driver — сырые HEX, оформление — на
переменных и стилях Kit. Пример отправлен в архив (страница «Архив», секция
«Пример · Справочник цветов (Driver) · 2026-10-23»).

Итерации по замечаниям пользователя:

1. Плитки заменены таблицей. Группа — это заголовок раздела и таблица.
2. Столбцы: Токен | Day (образец и значение) | Night (образец и значение) | Где
   применять. В ячейке «Токен» две строки: имя и путь.
3. У полупрозрачного цвета образец разделён пополам: слева цвет без альфы, справа
   с альфой. В подписи значение и альфа: `#000000 · 40%`.
4. Скругление разделённого образца: рамка 42×22 с фиксированным размером, без
   отступа, «обводка в раскладке» выключена. Половинки 21×22 занимают всю рамку.
   Углы обрезает сама рамка по `radius-s`, обводка рисуется поверх. С отступом 1 px
   прямые углы половинок вылезали за внутренний изгиб обводки.
5. Значение Night пишется всегда, даже если совпадает с Day. Метки «= day» нет.
6. Под заголовками нет подписей-счётчиков («12 токенов»), в навигации и содержании
   тоже нет счётчиков.
7. Нет полос-обзоров «квадраты всех токенов группы» над таблицей.
8. Навигация — ряд меток со ссылками на узлы групп.

## 2. Правила витрины (предложение)

Правила 6–8 пользователь задал для всех разделов витрин, а не только для цвета.

| # | Правило |
|---|---|
| В1 | Справочник токенов — таблица по группам: заголовок раздела, затем таблица. Плитки не используются. |
| В2 | Строка: Токен (имя и путь) · по столбцу на каждый режим (образец и значение) · связь (Core, если есть) · Где применять. |
| В3 | Значение пишется в каждом режиме, даже если совпадает с соседним. Метки «= day» нет. |
| В4 | Полупрозрачный цвет — разделённый образец: слева без альфы, справа с альфой. Подпись — `#RRGGBB · NN%`. |
| В5 | Образец: рамка с `radius-s` и `line-default`, содержимое без отступа, обводка вне раскладки, обрезка рамкой. |
| В6 | Без подписей-счётчиков под заголовками, без счётчиков в навигации и содержании. |
| В7 | Без полос-обзоров «квадраты всех токенов». |
| В8 | Навигация — метки со ссылками на узлы групп. |
| В9 | Образец залит переменной токена, а не HEX. Тогда он обновится сам; подписи HEX, alias и px остаются статичным текстом (см. «Открыто»). |
| В10 | Значение подписано `text-primary`, путь — `text-secondary` (AA). `text-muted` для значений не используется. |

## 3. Применено к Persefona

Страница **«Цвет»** (23:22, секция «Цвет», рамка 42:44) заменила две страницы,
«Цвет Core» и «Цвет Semantic». Слева колонка Core, справа колонка Semantic.

- В шапке страницы содержание «1. Core · 2. Semantic».
- Наверху каждой колонки карточка: название коллекции, описание и навигация-метки
  по группам.
- **Core** (колонка 900): группы graphite, malachite, amber, garnet, lapis, iolite,
  «Прозрачные». Столбцы: Токен | Значение | Используется в. Столбец «Используется
  в» собран из переменных файла: какие Semantic-токены и стили теней ссылаются на
  цвет. Пустое значение — «не используется» (сейчас это `malachite-10`, `amber-10`,
  `garnet-15`, `lapis-15`, `iolite-15`: рамки статусов сняты решением PD
  2026-10-23).
- **Semantic** (колонка 1216): группы Текст, Иконки, Фоны, Линии. Столбцы: Токен |
  Значение | Core | Где применять. «Где применять» взято из черновика токенов (#354)
  с поправкой на решения арт-дирекции (#358): метки без рамки, `line-focus-inverse`.
- Тема у Persefona одна (`light`), поэтому столбец значения один.
- Прозрачные `graphite-100-a*` показаны разделённым образцом (В4). Левая половина —
  сырой `#000000`: переменной для непрозрачного чёрного нет, и заводить её ради
  витрины не нужно.
- Строки и навигация склонированы из примера Driver: отступы, радиусы, зебра и
  стили текста — на переменных и стилях Kit.

Архив (страница «Архив»): «Пример · Справочник цветов (Driver) · 2026-10-23»,
«Цвет Core · плитки · до 2026-10-23», «Цвет Semantic · плитки · до 2026-10-23».
Пустые страницы удалены. Содержание обложки 4:87 обновлено.

Остальные витрины (Отступы и радиусы, Типографика, Тени) проверены по В6–В7:
счётчиков и полос-обзоров нет. Таблицами по В1–В2 они пока не сделаны.
