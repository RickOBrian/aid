## 2. Шаблон «гайд компонента»

Структура разделов — черновик `designer-build-format-rules.md` §4 (Штаб), у Standards —
«пробел 6» в PR #339 §4.1, не смержен. Шаблон Persefona опирается на неё. Если #339
изменит состав разделов, меняется только порядок блоков, а не их оформление.

Постоянные блоки 0–9 (ответ Designer · Components 2026-10-23); блок 10 существует
только до приёмки. Каждый блок — `IslandBlock` с `HeaderSection` внутри. Подвал
«Для инженера» выключен, пока Standards не решит иначе.

## 6. Вопросы

1. **Заголовок шапки.** §6.2 правила страниц: заголовок = имя страницы без значка,
   «TabBar · сборка». Сейчас на обложке — «TabBar · нижняя навигация Rider».
   ★а — заголовок «TabBar · сборка», «нижняя навигация Rider» переходит в начало
   описания; б — оставить заголовок контента (отход от §6.2).
2. **Ссылка на аудит.** ★а — последним пунктом `Contents`: «Аудит — для истории →»;
   б — в слот `How to Read` (он для «как читать», смысл другой).
3. **Плашка исключения.** ★а — Tone=Vivid Soft: исключение одобрено и не является
   ошибкой; б — Tone=Info.
4. **Ширина блока 5.** ★а — блок шире остальных (сетка 4 колонки, как сейчас);
   б — сетка в 2 колонки «день | ночь» по 16 строк при ширине 1216. Вариант б
   меняет раскладку демо — решает Designer · Components.
5. **Номера анатомии (У5).** Добавляют колонку «№» в таблицу блока 3 — правка
   контента. ★а — да, согласовать с Designer · Components; б — без маркеров.
6. **Подключение библиотеки.** Компоненты импортируются и без подключения. ★а —
   подключить Persefona Tokens и Components в Rider Components (делает человек в
   настройках файла: через API нельзя), чтобы дизайнеры видели, откуда оболочка;
   б — не подключать.
7. **Новые компоненты в Kit до 1.0.0.** ★а — три компонента и правка `TableCell` — в
   pending 1.0.0, без отдельной версии; б — после 1.0.0, minor.
